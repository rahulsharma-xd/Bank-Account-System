# 🏦 Bank Account System (Java)

A simple **Bank Account Management System** built using Java to practice Object-Oriented Programming (OOP) concepts.

## 📌 About the Project

This project demonstrates basic banking operations using Java classes, objects, constructors, and methods. It allows users to deposit money, withdraw money, check their account balance, and display account details.

## ✨ Features

- 👤 Store account holder name
- 🔢 Store account number
- 💰 Deposit money
- 💸 Withdraw money
- ✅ Check available balance before withdrawal
- 📋 Display account details

## 🛠️ Technologies Used

- **Language:** Java
- **Concepts:** Classes, Objects, Constructors, Methods, Conditional Statements
- **IDE:** IntelliJ IDEA (if used)

## ▶️ How to Run

### Prerequisites

- Install the Java JDK.
- Install an IDE such as IntelliJ IDEA, or use a terminal.

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/rahulsharma-xd/Bank-Account-System.git
   ```

2. Open the project folder:

   ```bash
   cd Bank-Account-System
   ```

3. Compile the Java file:

   ```bash
   javac Bank_Account_System/src/Main.java
   ```

4. Run the program:

   ```bash
   java -cp Bank_Account_System/src Main
   ```
